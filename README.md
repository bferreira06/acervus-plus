# Acervus+

Sistema de gerenciamento de acervo pessoal desenvolvido em Java 21, Spring Boot e MySQL.

## Funcionalidades
- Cadastro e consulta de obras.
- Cadastro e consulta de edições.
- Cadastro e consulta de exemplares.
- Geração de relatórios do acervo.

## Tecnologias
- Java 21
- Spring Boot
- Gradle
- Spring Data JPA
- MySQL

## Padrões de projeto GoF
- Builder
- Strategy
- Factory Method

## Execução

Configure a conexão com o banco de dados MySQL no arquivo `application.properties` e execute:

```bash
./gradlew bootRun
```

No Windows:

```powershell
.\gradlew.bat bootRun
```
